## 🟠 脆弱性情報

### [Apache HTTP Server patches critical HTTP/2 remote code execution flaw](https://www.bleepingcomputer.com/news/security/apache-http-server-patches-critical-http-2-remote-code-execution-flaw/)
- **概要**: Apache HTTP Serverのmod_http2モジュールに、未認証の攻撃者がリモートコード実行（RCE）を行える深刻な脆弱性（CVE-2026-119618）が発見されました。assign_headers()におけるレースコンディションによりヒープメモリが破損する恐れがあります。
- **CVSS**: 9.8（Red Hatによるスコア）
- **対応**: 修正済みバージョン2.4.71がリリースされています。HTTP/2が無効な環境（デフォルトはオフ）は影響を受けません。

### [New Windows SignDrop zero-day gives hackers SYSTEM privileges](https://www.bleepingcomputer.com/news/security/new-windows-signdrop-zero-day-gives-hackers-system-privileges/)
- **概要**: WindowsのCLFS（Common Log File System）ドライバーにおけるゼロデイ脆弱性「SignDrop」の実証コードが公開されました。攻撃者がログ作成処理を悪用することで、ローカルからSYSTEM権限を取得できる可能性があります。
- **CVSS**: 不明
- **対応**: 記事執筆時点でMicrosoftからの公式確認、CVE割り当て、または修正パッチは発行されていません。

### [New N-able "4EverAble2Shell" zero-day exploited hours after PoC released](https://www.bleepingcomputer.com/news/security/new-n-able-4everable2shell-zero-day-exploited-hours-after-poc-released/)
- **概要**: N-able N-centralにおけるゼロデイ脆弱性「4EverAble2Shell」および「Agent2Shell」のPoC公開直後から、暗号資産マイナーを設置する攻撃が野外で確認されました。4EverAble2ShellはApache Axisの脆弱性（CVE-2026-90436）などを組み合わせて実行されます。
- **CVSS**: 9.3（CVE-2026-125883）、8.7（CVE-2026-125878）、その他は不明
- **対応**: N-ableは未認証で悪用可能な脆弱性のパッチを緊急リリースしており、その他の脆弱性についても順次ホットフィックスを提供するとしています。

### [Critical Red Hat Quay Flaw Lets Attackers Read and Overwrite All Private Container Images in a Registry](https://thehackernews.com/2026/11/critical-red-hat-quay-flaw-lets.html)
- **概要**: Red Hat Quayにおいて、攻撃者が自身の公開鍵を信頼されたキーとして登録し、レジストリ内の全リポジトリにある非公開コンテナイメージの読み取りや上書きが可能になる脆弱性（CVE-2026-123710）が公表されました。
- **CVSS**: 9.8
- **対応**: Red Hatは対象となるQuay 3の8つのブランチに対して修正ビルドをリリースしています。

### [Citrix Patches 12 NetScaler and Secure Access Client Flaws, Including Authentication Bypass](https://thehackernews.com/2026/11/citrix-patches-12-netscaler-and-secure.html)
- **概要**: Citrixは、NetScaler ADC、NetScaler Gateway、NetScaler Console、およびSecure Access Clientにおける認証バイパスやDoSにつながる12件のセキュリティ脆弱性の修正パッチを公開しました。
- **CVSS**: 不明
- **対応**: Citrixは対象製品の利用者にセキュリティアップデートの速やかな適用を求めています。

### [Chrome, Firefox Updates Patch Over 180 Vulnerabilities](https://www.securityweek.com/chrome-firefox-updates-patch-180-vulnerabilities/)

### [Google Cloud Warns Three AMD Turin CPU Flaws Could Leak Data Across Processes in VMs](https://thehackernews.com/2026/11/google-cloud-warns-three-amd-turin-cpu.html)
- **概要**: 第5世代AMD EPYC（Turin）プロセッサに、同一VM内の別プロセスからデータを推測される可能性がある3つのサイドチャネル脆弱性（CVE-2024-36350、CVE-2024-36357、CVE-2026-0004）が存在することが報告されました。
