## 🟠 脆弱性情報
### [Critical Langflow flaw exploited to steal OpenAI and AWS keys](https://www.bleepingcomputer.com/news/security/critical-langflow-flaw-exploited-to-steal-openai-and-aws-keys/)
- **概要**: AIアプリケーション構築フレームワークLangflowの認証なしリモートコード実行脆弱性(CVE-2026-0768)が悪用され、資格情報、トークン、キーが窃取されている。
- **CVSS**: 9.8
- **対応**: Langflowの全リリース（バージョン1.4.2まで）が影響を受ける。ZDIを通じて2025年7月に報告され、2026年1月にゼロデイとして公開された。パッチ適用が推奨される。

### [Nearly 22,000 Microsoft Exchange servers vulnerable to hijack attacks](https://www.bleepingcomputer.com/news/security/nearly-22-000-microsoft-exchange-servers-vulnerable-to-hijack-attacks/)
- **概要**: 約22,000台のオンラインで公開されているMicrosoft Exchangeサーバーが、ユーザーメールボックスをハイジャックできる高深刻度の認証バイパス脆弱性(CVE-2026-62911)に対して未パッチのままである。脆弱性のエクスプロイトコードは既にオンラインで利用可能と報告されている。
- **CVSS**: high-severity
- **対応**: Microsoftは2026年8月のPatch Tuesdayでパッチを提供済み。早急なアップデートが推奨される。Exchange Server 2016および2019はExtended Security Updates Program (ESU) 経由でのみセキュリティアップデートを受け取るため、可能であればサーバーを内部からのみアクセス可能にし、交換を検討すべき。

### [Attackers Exploit Critical JFrog Artifactory Flaw to Mint Admin Tokens Days After Disclosure](https://thehackernews.com/2026/09/attackers-exploit-critical-jfrog.html)
- **概要**: JFrog Artifactoryの認証バイパスの重大な脆弱性(CVE-2026-82329)が公開されてから数日後に攻撃者によって悪用されており、デフォルト設定のインスタンスで、認証なしの攻撃者が管理権限を取得可能となる。
- **CVSS**: 9.8
- **対応**: JFrogは2026年8月28日にArtifactoryバージョン7.161.20でパッチをリリース済み。自社ホスト環境の顧客はパッチ適用済みのバージョン（7.111.21, 7.117.28, 7.125.20, 7.133.29, 7.146.38, 7.161.20など）へのアップデートが推奨される。

### [13 Malicious Packagist Packages Target Unpatched iPhones to Steal Crypto Wallet Seeds](https://thehackernews.com/2026/09/13-malicious-packagist-packages-target-unpatched-iphones-to-steal-crypto-wallet-seeds/)
- **概要**: Packagist上で発見された13の悪意あるComposerテーマパッケージが、ベトナムの映画・漫画ストリーミングサイトにJavaScriptを注入し、未パッチのiOSデバイスにスパイウェアを配備している。これにはWebkitの脆弱性CVE-2025-31277、CVE-2025-43529が悪用される。
- **CVSS**: 不明
- **対応**: CVE-2025-31277はバージョン18.6でパッチ済み。脆弱性の修正を含む最新バージョンへの更新が推奨される。
