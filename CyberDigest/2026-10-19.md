## 🟠 脆弱性情報

### [Hackers exploit SiteGuard WAF flaw to run commands as admins](https://www.bleepingcomputer.com/news/security/hackers-explot-siteguard-waf-flaw-to-run-commands-as-system-root/)
- **概要**: SiteGuard Server EditionのWebアプリケーションファイアウォール（WAF）に、OSコマンドインジェクションの脆弱性（CVE-2026-106931）が存在し、攻撃者が影響を受けるマシン上でrootまたはSYSTEM権限でコマンドを実行できる可能性があります。この脆弱性は「Critical」と評価され、既に悪用が確認されています。
- **CVSS**: Critical
- **対応**: ベンダーは脆弱性を修正したバージョンへのアップグレードを推奨しており、アップグレードが困難な場合は統計処理に使用されるファイルを置き換えるパッチを提供しています。また、統計機能を無効化することでも影響を回避できます。

### [Drupal patches critical RCE flaws, warns exploits may emerge soon](https://www.bleepingcomputer.com/news/security/drupal-patches-critical-rce-flaws-warns-exploit-may-emerge-soon/)

- **CVSS**: 不明
- **対応**: 管理者は、脆弱性公開後すぐにエクスプロイトが開発される可能性があるため、速やかにアップデートを適用することが強く推奨されています。

### [Critical BlockStrap flaw lets hackers run code on Magento servers](https://www.bleepingcomputer.com/news/security/critical-blockstrap-flaw-lets-hackers-run-code-on-magento-servers/)

- **CVSS**: 不明
- **対応**: 攻撃はまだ観測されていませんが、Adobeは10月13日にこの脆弱性を修正するアドバイザリを公開しており、Sansecは早急なパッチ適用を促しています。

### [Microsoft: October Windows update may break Smart App Control](https://www.bleepingcomputer.com/news/microsoft/kb5127648-windows-security-update-may-break-smart-app-control/)

### [Researchers Demonstrate OpenBSD Root Exploit Chaining 37-Year-Old Shared-Memory Bug](https://thehackernews.com/2026/10/researchers-demonstrate-openbsd-root-exploit-chaining-37-year-old-shared-memory-bug/)
